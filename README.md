# 📚 OnlineBookStore
A Java-based web application for an online bookstore, built using Servlets and JSP, with MySQL as the backend database and deployed on Apache Tomcat.

# ✨ Features
- User Registration & Login – New users can sign up and log in securely.
- Browse & Search Books – Users can view available books and search by title/author/category.
- Shopping Cart – Add books to cart, update quantities, and remove items.
- Order/Checkout – Users can place orders for the books in their cart.
- Admin Panel – Admin users can add, update, or remove books from the catalog.

# 🛠️ Tech Stack
Language: Java
Web Layer: Servlets, JSP
Database: MySQL
Server: Apache Tomcat v10.1
IDE: Eclipse

# ⚙️ Setup & Installation
# Prerequisites
JDK 8 or above
Apache Tomcat v10.1
MySQL Server
Eclipse IDE (with Web Tools Platform)
